# 智能车下位机示例代码

```
firmware/
├── arduino_pid/          # Arduino版本
│   └── arduino_pid.ino
├── stm32_pid/            # STM32版本
│   └── main.c
└── README.md             # 本文件
```

## 通信协议

### 下位机发送格式
```
P=1.00,I=0.10,D=0.01,actual=95.50,target=100.00,error=4.50
```

| 字段 | 说明 |
|------|------|
| P | 当前P参数 |
| I | 当前I参数 |
| D | 当前D参数 |
| actual | 实际速度值 |
| target | 目标速度值 |
| error | 当前误差 |

### 上位机发送格式
```
P=1.50,I=0.20,D=0.02
```

### 支持的命令

| 命令 | 说明 | 示例 |
|------|------|------|
| P=,I=,D= | 设置PID参数 | `P=1.50,I=0.20,D=0.02` |
| STATUS | 查询状态 | `STATUS` |
| RESET | 重置PID | `RESET` |
| STOP | 停止电机 | `STOP` |
| SETPOINT= | 设置目标速度 | `SETPOINT=100` |

## Arduino使用方法

### 1. 硬件连接

```
Arduino Uno/Nano
├── D9  (ENA) → 左电机PWM
├── D8  (IN1) → 左电机方向
├── D7  (IN2) → 左电机方向
├── D10 (ENB) → 右电机PWM
├── D6  (IN3) → 右电机方向
├── D5  (IN4) → 右电机方向
├── D2  → 左编码器A（中断）
├── D4  → 左编码器B
├── D3  → 右编码器A（中断）
└── D11 → 右编码器B
```

### 2. 烧录代码

1. 打开Arduino IDE
2. 打开 `arduino_pid/arduino_pid.ino`
3. 选择开发板和串口
4. 点击上传

### 3. 测试通信

打开串口监视器，波特率115200，发送：
```
P=1.00,I=0.10,D=0.01
```

应该看到回复：
```
PID Updated: P=1.00, I=0.10, D=0.01
```

## STM32使用方法

### 1. 硬件连接

```
STM32F103C8T6
├── PA0 (TIM2_CH1) → 左电机PWM
├── PA1 (TIM2_CH2) → 右电机PWM
├── PA4 → 左电机方向
├── PA5 → 左电机方向
├── PA6 → 右电机方向
├── PA7 → 右电机方向
├── PA6 (TIM3_CH1) → 左编码器A
├── PA7 (TIM3_CH2) → 左编码器B
├── PB6 (TIM4_CH1) → 右编码器A
├── PB7 (TIM4_CH2) → 右编码器B
├── PA9  (USART1_TX) → 串口TX
└── PA10 (USART1_RX) → 串口RX
```

### 2. 编译烧录

1. 使用Keil MDK或STM32CubeIDE
2. 导入工程
3. 编译并烧录

## 与上位机配合使用

1. 打开上位机软件 `python main.py`
2. 选择串口，设置波特率115200
3. 点击「连接」
4. 切换到「调参分析」选项卡
5. 设置目标速度（设定值）
6. 点击「开始分析」
7. 在「串口调试」选项卡发送PID参数
8. 观察实时曲线和性能指标

## PID调参建议

1. **先调P**：从小到大，直到系统开始振荡
2. **再调I**：从小到大，消除稳态误差
3. **最后调D**：从小到大，减少超调

### 常见问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 振荡 | P过大 | 减小P |
| 响应慢 | P过小 | 增大P |
| 有稳态误差 | I过小 | 增大I |
| 超调大 | D过小 | 增大D |
