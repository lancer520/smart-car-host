# 智能车上位机调试软件设计文档

## [S1] 问题

智能车开发过程中需要实时调试PID参数、监控速度曲线、记录数据。现有调试工具功能分散，缺乏集成化的调试环境。

## [S2] 解决方案概述

开发一个基于Python+PyQt的跨平台上位机调试软件，集成串口通信、实时PID曲线绘制、参数调节、数据记录和回放等功能。

## [S3] 核心功能

### 3.1 串口通信模块
- 支持Windows/macOS/Linux跨平台串口通信
- 可配置波特率、数据位、停止位、校验位
- 支持多串口同时连接
- 自定义协议解析器（先实现常见文本格式，后续支持二进制协议）

### 3.2 实时数据可视化
- 实时绘制PID曲线（P、I、D三条曲线）
- 支持多路PID曲线选择显示
- 曲线缩放、平移、时间轴调整
- 数据点标记和数值显示

### 3.3 参数调节界面
- PID参数实时调节滑块
- 参数范围限制和步进设置
- 参数预设保存和加载
- 参数历史记录和对比

### 3.4 数据记录与回放
- 同时记录原始串口数据和解析后的PID数据
- 支持多种导出格式：TXT、CSV、SQLite数据库
- 数据录制和回放功能
- 时间戳标记和事件标记

### 3.5 自动调参功能
- 基于Ziegler-Nichols等算法的自动调参
- 调参过程可视化
- 调参结果评估和保存

### 4.2 技术栈
- **GUI框架**: PyQt5/PyQt6
- **串口通信**: pyserial
- **数据可视化**: pyqtgraph（实时性能好）
- **数据处理**: pandas, numpy
- **日志记录**: logging, sqlite3
- **配置管理**: configparser, json
- **打包发布**: PyInstaller

### 4.3 数据流设计
1. 串口接收原始数据 → 协议解析器 → 数据模型
2. 数据模型 → 视图更新（曲线、数值显示）
3. 用户调节参数 → 控制器 → 串口发送命令
4. 数据记录器同时记录原始数据和解析数据

1. 能够成功连接串口并收发数据
2. 实时绘制PID曲线，延迟<100ms
3. 参数调节能够实时发送到下位机
4. 数据记录完整，支持多种格式导出

6. 界面响应流畅，无卡顿
